# Telegram Mini App — Demo UI

Это локальный прототип интерфейса по предоставленному скриншоту.

Что есть:
- адаптивная верстка под Telegram Mini App;
- тёмный интерфейс;
- список криптопар в стиле TradingView;
- переключение таймфреймов;
- переключение активов;
- кнопка «Получить сигнал»;
- история тестовых нажатий;
- подключение Telegram WebApp SDK.

Важно: это именно демонстрационный интерфейс. Он не получает реальные котировки и не формирует торговые рекомендации. Направление сигнала намеренно не показывается.

Для локального запуска:
1. Открой папку в VS Code.
2. Запусти index.html через Live Server.
3. Для реального Telegram Mini App страницу нужно разместить на HTTPS-хостинге и указать её URL в настройках Web App у бота.
